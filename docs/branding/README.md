# Data Real Estate / Green Vista branding

User supplied the society and company brochure references on 2026-11-04 and requested their use throughout the CRM and reports. Company: **Data Real Estate**. Society: **Green Vista Housing Scheme**.

The transparent, scalable [company SVG](../../public/branding/data-real-estate.svg) and [society SVG](../../public/branding/green-vista.svg) are manually recreated artwork, **not recovered original design files**. Low-resolution references cannot establish exact curves, fonts or colours. The company recreation uses olive gold `#998447`; the society uses dark green `#173e30` and a gold gradient. Both contain editable vector geometry and text; installed serif/sans fonts can affect rendering. These are an initial recreation requiring visual review before commercial print production.

Original supplied references are preserved as [company brochure](references/data-real-estate-brochure.png) and [society brochure](references/green-vista-brochure.png). Do not publish those brochure crops as the master logos.

[BrandHeader](../../resources/js/components/brand-header.tsx) provides the paired company/society header for issued receipts and future printable reports. CRM navigation and sign-in branding use the same public assets. This installation's presentation is branded specifically for this company/society; replacing presentation assets remains possible for another installation. Existing persisted inventory/company profile names have not been silently rewritten.

Remaining: compare the recreations visually with the supplied references, add formal print/report templates as those modules are implemented, and move installation branding into administrable settings when supporting other installations. A reusable header alone does not implement all reports or PDF export.
